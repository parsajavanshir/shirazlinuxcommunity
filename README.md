# Shiraz Linux Community

Website repository for **Shiraz Linux Community (جامعه لینوکسی شیراز)**, a local community for Linux, free/open-source software, technical meetups, and related events in Shiraz.

## Contents

- Community landing page
- Meetup and conference information
- Community/about section
- Static assets and responsive styling

## Stack

- HTML
- CSS
- JavaScript
- Bootstrap

## Local preview

Open `index.html` in a browser or serve the repository with any static HTTP server.

## Contributing

Improvements to the website, accessibility, responsive design, and content are welcome through pull requests.
